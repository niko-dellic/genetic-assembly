# Genetic Assembly

A high-performance WebAssembly-based Multi-Objective Optimization library using NSGA-II and NSGA-III genetic algorithms, written in Rust.

## 🚀 Features

- **Fast**: Compiled to WebAssembly for near-native performance
- **Parallel**: Island model with Web Workers for multi-threaded optimization
- **Flexible**: Supports both linear and custom non-linear objectives
- **Real-time**: Progress callbacks for live visualization
- **Type-safe**: Full TypeScript definitions

## 📖 Usage

### Basic Example

```typescript
import init, { solve_json } from "./pkg/index.js";

await init(); // Initialize WASM

const spec = {
  algorithm: "nsga2",
  num_vars: 3,
  population_size: 100,
  num_iterations: 200,
  crossover_rate: 0.9,
  mutation_rate: 0.1,
  num_offsprings: 50,
  objectives: [
    [1, 2, 3], // Minimize: 1x₁ + 2x₂ + 3x₃
    [3, 2, 1], // Minimize: 3x₁ + 2x₂ + 1x₃
  ],
  workers: true, // Use parallel workers
};

const result = await solve_json(spec);
console.log(result.pareto); // Pareto-optimal solutions
```

### Custom Evaluation Functions

```typescript
import { solve_with_custom_eval } from "./pkg/index.js";

const spec = {
  algorithm: "nsga2",
  num_vars: 3,
  population_size: 100,
  num_iterations: 200,
  crossover_rate: 0.9,
  mutation_rate: 0.1,
  num_offsprings: 50,
  workers: 4, // Use 4 workers
};

// Custom non-linear objectives
const evalFn = (genes) => {
  const [x, y, z] = genes;
  return [
    x * x + y * y, // Minimize: x² + y²
    Math.sin(z) + x - y, // Minimize: sin(z) + x - y
  ];
};

const result = await solve_with_custom_eval(spec, evalFn);
```

## 🔧 API

### `solve_json(spec, progressCallback?, workerCallbacks?)`

Solve optimization with linear objective matrices.

**Returns**: `OptimizationResult` or `Promise<OptimizationResult>` (if using workers)

### `solve_with_custom_eval(spec, evalFn, progressCallback?, workerCallbacks?)`

Solve optimization with custom JavaScript evaluation function.

**Returns**: `OptimizationResult` or `Promise<OptimizationResult>` (if using workers)
