# Genetic Assembly

A library for reproducible, multi-objective optimization. Define what can change in your application, measure competing goals, and compare candidate designs with a baseline.

Your model stays in your application. The TypeScript SDK connects it to a local Rust NSGA-II companion, with optional simulation, Three.js, and visualization integrations.
