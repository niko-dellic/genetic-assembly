# grabm neighborhood example

This application-owned example lives in `examples/neighborhood/`. It holds eight residents and their authored shopping needs fixed while evolving bounded graph positions, shop capacity, and an optional link. It compares service fulfillment, accessibility, and an illustrative construction proxy.

[Run the example](./live-neighborhood) · [Examples dashboard](./examples) · [Example source](https://github.com/niko-dellic/genetic-assembly/tree/main/examples/neighborhood)

The authoritative grabm integration guide is maintained in [grabm](https://github.com/niko-dellic/grabm/blob/main/docs/guides/optimization.md). General worker ownership, seeds, lifecycle, and observation belong to [Genetic Assembly's runtime guide](./runtime.md).
